# CRM Diagnostics – nedladdning / download

**Svenska.** Ladda ner den senaste installationsfilen under
[Releases](../../releases/latest) (`CRM-Diagnostics-Setup-<version>.exe`) och kör den.
Ingen administratörsbehörighet eller Python behövs. Om Windows visar
"Windows skyddade datorn", klicka **Mer information → Kör ändå**.
Programmet kräver en licensnyckel, som du får från leverantören.
Alla dina CRM-data bearbetas lokalt på din dator.

**English.** Download the latest installer from
[Releases](../../releases/latest) and run it. No admin rights or Python needed.
If Windows shows "Windows protected your PC", click **More info → Run anyway**.
A licence key from the vendor is required. All CRM data is processed locally.

This repository only holds the installer files.
